`create-plico` generates the internal-ops starter, and the `plico` CLI validates
and runs it.

<Callout type="warn">
  Plico packages are not published to npm yet. Until they are, build the repository
  (`pnpm install && pnpm build`) and run the CLIs from `packages/create-plico/dist/cli.js`
  and `packages/cli/dist/cli.js`.
</Callout>

<Steps>
  <Step>
    ### Create and check a project

    ```bash
    create-plico my-agent
    plico validate my-agent
    plico run --dry my-agent
    ```

    `plico validate` reports diagnostics for missing files, duplicate tool names, and
    invalid config. `plico run --dry` runs the project with a scripted model, so it
    needs no API key.
  </Step>
  <Step>
    ### Open Studio

    ```bash
    plico serve --studio my-agent
    ```

    Studio shows the run's event history and lets you chat, approve tool calls, and
    browse artifacts. See [Studio](/docs/studio).
  </Step>
  <Step>
    ### Use `--help`

    `plico validate --help` shows validation usage. Unknown flags are reported as
    errors, and `plico runs` reports clearly when a project has no saved runs.
  </Step>
</Steps>
